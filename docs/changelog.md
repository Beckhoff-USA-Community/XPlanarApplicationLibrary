# Changelog

## 2.0.7.1 (2026-07-17)
### Fixed
* Patch for move relative commands

## 2.0.7 (2026-07-10)

### Added
* I_StationProcess so a process function block can be assigned to a station base, offering composition as an alternative to inheritance
