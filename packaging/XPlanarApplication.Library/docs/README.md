# XPlanar Application PLC Library

XPlanarApplication is a TwinCAT 3 PLC library built on the base functionality of TF5890 XPlanar. It provides a consistent and flexible starting point for XPlanar applications: movers, stations, tracks and tiles with queueing, motion command interfaces and station processes.

The package installs the library into the XAE library repository, ready to add as a reference.

TF5890 TwinCAT 3 XPlanar and TF5400 TwinCAT 3 Advanced Motion Pack must be installed to build a project that uses the library. Version 2.x of the library needs TF5890 5.0.x and TF5400 3.4.45 or greater.

Project home and documentation: https://github.com/Beckhoff-USA-Community/XPlanarApplicationLibrary
